# Strategy rating rubric (for blinded raters)

Rate each strategy on four dimensions, 1–5. Use the anchors; half points are not allowed. Add a one-line comment per dimension when you give 1 or 5.

**Feasibility** — Can this be implemented with the documented variables as specified?
1 outcome or key exposure not identifiable from documented variables · 3 implementable with a defensible proxy or derivation · 5 directly implementable as written.

**Alignment with prior findings** — Does it extend the input manuscripts coherently?
1 contradicts or ignores the manuscripts' framework · 3 consistent but loosely connected · 5 a natural next step that uses the manuscripts' own constructs (e.g. PCA alignment, timing of sex effects).

**Novelty vs triviality** — Is the question open?
1 already answered by the input manuscripts or textbook knowledge · 3 incremental · 5 a genuinely untested, informative question.

**Interpretability** — Would a domain expert understand what result would support or refute the gap?
1 unclear what the model would show · 3 understandable with effort · 5 question, variables, interactions and expected direction are all explicit.

Also record: *recovery* (0/1/2) when asked — does this strategy correspond to what the held-out manuscript actually tested?
